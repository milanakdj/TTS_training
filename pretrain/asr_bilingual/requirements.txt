# NeMo ASR environment for the nemotron Nepali+English work.
# Mirrors the working venv at /workspace/venvs/nemo (python 3.10.21), which is
# what every run in pretrain/asr_bilingual/ was trained and evaluated with.
#
# DO NOT `pip install -r` this file on its own and expect a trainable NeMo.
# Two things pip will not do for you on this box, both of which surface far from
# their cause -- see the install order at the bottom.
#
#   torch==2.14.0+cu126   NeMo 3.0.0 resolves torch 2.14.0+cu130, but the driver
#                         here (535.288.01) tops out at CUDA 12.6, so
#                         torch.cuda.is_available() is False with a misleading
#                         "driver is too old" warning. Same version, right build.
#   numba-cuda            not pulled by nemo_toolkit[asr] -- it lives behind the
#                         cu12/cu13 extras. Without it RNN-T training dies at the
#                         first step with "Signature mismatch: 2 argument types
#                         given, but function takes 1 arguments" from inside
#                         numba/core/untyped_passes.py, naming nothing useful.
