# Nepali TTS Synthetic v2

383,298 synthetic Nepali (`ne`) speech/text pairs, 24 kHz mono 16-bit WAV embedded
as-is (no re-encode, no resampling).

Generated by the `synthetic_pipeline` in `milanakdj/TTS_training`: Edge TTS
synthesis → optional voice conversion against a pool of 600 real multi-speaker
reference clips → ASR-based QC gate on character error rate.

## Read this before training on it

**Only 48% of rows are voice-converted.** Each row carries a `kept` field
recording which stage's audio actually survived QC:

| `kept` | Rows | What the audio is |
|---|---|---|
| `raw_fallback` | 199,624 (52.1%) | Plain Edge TTS output. Voice conversion **failed** the CER gate, so the pre-VC synthesis was kept instead. |
| `vc` | 183,674 (47.9%) | Voice-converted toward a real reference speaker, passed the CER gate. |

So this is **not** a uniform multi-speaker corpus. Just over half of it is two
Edge TTS voices speaking in their own timbre; the rest is those voices converted
toward real speakers. Filter on `kept == "vc"` if you need the converted subset,
and treat `voice` as the *source* voice, not the audible speaker identity.

Speaker source distribution:

- `ne-NP-HemkalaNeural` — 200,388 rows
- `ne-NP-SagarNeural` — 182,910 rows

## Size

| | |
|---|---|
| Rows | 383,298 |
| Audio | ~871 hours (~141 GB) |
| Clip length | mean 8.2 s, median 7.5 s, range 2.4–44.7 s |
| Format | 24 kHz mono 16-bit WAV, embedded uncompressed |
| Text | mean 101 characters per row |
| Shards | 48 parquet files, 8,000 rows each |

Duration is estimated from a 3,000-file sample of the actual WAVs, not from a
declared field.

## Columns

| Column | Type | What it holds |
|---|---|---|
| `id` | `string` | Sentence id from the source text pool. Unique, but sparse (`0`–`579875`) — dropped rows keep their ids, so ids are not contiguous. |
| `text` | `string` | The Nepali sentence that was synthesized: the exact TTS input, not an ASR transcript. 16–2,750 characters, median 94. |
| `audio` | `audio` (24 kHz) | The kept clip, embedded as raw WAV bytes (mono 16-bit, no re-encode, no resample). `audio["path"]` ends in `_vc.wav` or `_raw.wav`, matching `kept`. |
| `voice` | `string` | Edge TTS voice used for synthesis: `ne-NP-HemkalaNeural` (200,388) or `ne-NP-SagarNeural` (182,910). This is the **source** voice — when `kept == "vc"` it is not the audible speaker. |
| `kept` | `string` | Which stage's audio survived QC: `vc` or `raw_fallback`. See the table above. |
| `synth_cer` | `float32` | CER of the raw Edge TTS audio against `text`, from faster-whisper `large-v3-turbo`. Always < 0.3 here. |
| `vc_cer` | `float32` | CER of the voice-converted audio, same measure. Populated on every row: < 0.3 when `kept == "vc"`, ≥ 0.3 (up to 14.1) when `kept == "raw_fallback"` — that failure is *why* the row fell back. |
| `synth_pass` | `bool` | `synth_cer < 0.3`. Always `true` in this repo — a row with a failing synth was either VC-rescued or dropped, and dropped rows are not published. |
| `vc_pass` | `bool` | `vc_cer < 0.3`. Equivalent to `kept == "vc"`. |
| `ref_pool_version` | `string` | Reference-speaker pool id: `v2_real_multispeaker` on 329,380 rows, **null on 53,918** (14.1%). The field was only added partway through the run; the pool itself did not change. |

## QC

Both CER fields come from the same ASR pass against the known input text, gated at
CER < 0.3. Among kept rows, median `vc_cer` is 0.244 (p90 0.289) for `kept == "vc"`
and median `synth_cer` is 0.235 (p90 0.286) for `kept == "raw_fallback"`. These are
one QC model's error on this audio — use them as a **relative** filter to drop the
worst tail, not as an absolute quality score.

## Quick start

```python
from datasets import load_dataset

ds = load_dataset("milanakdj/nepali-tts-synthetic-v2", split="train")
clean = ds.filter(lambda r: r["kept"] == "vc" and r["vc_cer"] < 0.15)
```

The full set is ~141 GB. To try one 8,000-row shard (~3 GB) instead:

```python
from huggingface_hub import hf_hub_download
from datasets import Audio, Dataset

path = hf_hub_download(
    "milanakdj/nepali-tts-synthetic-v2",
    "data/train-00000-of-00048.parquet",
    repo_type="dataset",
)
shard = Dataset.from_parquet(path).cast_column("audio", Audio(sampling_rate=24000))
print(shard[0]["text"], shard[0]["audio"]["array"].shape)
```

## Provenance

- The run was **stopped early by choice at 383,298 of a 500,000-row target (77%)** —
  the remaining ~117k rows would have cost ~43 more hours. The run was healthy and
  checkpointed when halted, and remains resumable; the dataset is simply not the
  round number the pipeline was configured for.
- Only QC-passing rows are published. 193,792 dropped and 2,766 errored rows are **not** here.
- Text comes from a 900k-sentence scraped Nepali pool. Expect TTS artifacts and
  text-normalization oddities — this is pretraining/augmentation data, not an eval set.
- Earlier run: `himalaya-ai/Nepali-tts-synthetic`, 140,066 examples at 16 kHz, kept
  separately and untouched.
